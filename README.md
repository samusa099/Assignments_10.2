## 📌 Overview

A restaurant-themed front-end project featuring promotional imagery, menu cards, event content, reservation inputs, branded typography, and a responsive Bootstrap layout.

- Upcoming-events showcase
- Table-reservation interface

```bash
git clone https://github.com/samusa099/Assignments_10.2.git
cd Assignments_10.2
```

Open `index.html` in a browser or use **VS Code Live Server**.

> Order, reservation, cart, and payment functions are not connected to backend services.
