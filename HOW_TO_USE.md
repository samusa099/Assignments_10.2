# 📘 How, Where & Why to Use This Project

## Project
**Burger House — PSD to HTML Landing Page**

## Why Use It

This repository demonstrates how a restaurant-themed PSD design can be converted into a structured front-end website using HTML5, CSS3, Bootstrap, Google Fonts, Font Awesome, image overlays, product cards, and a reservation interface.

Use it to:

- Practise PSD-to-HTML implementation
- Study restaurant and food-brand landing pages
- Learn image-overlay and promotional layouts
- Build portfolio evidence for front-end design
- Review Bootstrap cards, grids, and form layouts

## Where It Can Be Used

- Front-end portfolios
- Restaurant website prototypes
- Classroom and bootcamp assignments
- Food campaign landing pages
- UI practice for menu and reservation interfaces

> Replace all demo contact details, prices, menu content, imagery, and reservation actions before real business use.

## How to Use It

```bash
git clone https://github.com/samusa099/Assignments_10.2.git
cd Assignments_10.2
```

Open `index.html` in a browser or use **VS Code Live Server**.

### Customisation Steps

1. Update the brand, navigation, hero, menu, events, reservation, and footer content in `index.html`.
2. Replace burger and promotional imagery inside `images/`.
3. Edit visual design and responsive behaviour in `css/style.css`.
4. Replace phone, address, email, and social links.
5. Connect reservation and order buttons to real services if needed.

## File Guide

| File or Folder | Purpose |
|---|---|
| `index.html` | Complete restaurant landing-page structure |
| `css/style.css` | Layout, typography, image positioning, and visual styling |
| `images/` | Logo, banners, burgers, promotional, and footer assets |
| `README.md` | Project overview and quick start |
| `HOW_TO_USE.md` | Detailed usage, customisation, and extension guide |

## Recommended Workflow

1. Review the original rendered design.
2. Replace brand content and images first.
3. Check image dimensions before changing layout rules.
4. Test menu cards and forms at each breakpoint.
5. Add accessible labels and valid link targets.
6. Optimise images before deployment.

## Suitable Practice Tasks

- Build a dynamic menu from JSON
- Add working reservation validation
- Connect order buttons to a cart
- Improve mobile navigation
- Add a real image carousel
- Deploy with GitHub Pages

## Limitations

- Static front-end demonstration
- No ordering, cart, reservation, or payment backend
- Form data is not submitted
- Demo assets require licensing review for commercial use
